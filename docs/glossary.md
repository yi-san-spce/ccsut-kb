# 术语表

第一次在文档里碰到看不懂的词，来这里查。术语第一次出现的地方也会尽量就地解释，本表兜底。

## 课表与数据

- **数据集（dataset）**：学校教务系统的班级课表数据全量抓取产物（228 个班），构建时打包进 APK，之后可被数据热更整体替换。文件在 `data/` 下。
- **生效课表**：内置数据集叠加本机编辑后的最终结果——App 屏幕、小组件、提醒看到的都是它。见 [architecture.md](原理与接口/architecture.md)。
- **覆盖层（UserEdits）**：用户本机编辑的存储形式，`filesDir/user_edits.json` 里的 `add` / `modify` / `hide` 三类记录。学校原始数据只读不改，所有改动都记在覆盖层上。
- **快照（ClassCache）**：生效课表的轻量副本（几十 KB）。小组件和提醒进程读它，避免每次解析 4MB 的全量数据集。
- **连堂**：同一节课连续占相邻节次（如大学英语占周五第 1-2 节）。教务接口把连堂表达成相邻两条记录，App 的 `Merger` 负责折叠。
- **合班**：多个班级一起上的课，字段 `jxbzc` 列出合上的班级。
- **单双周**：隔周上课（如单周上、双周不上）。接口字段 `zcstr` 已展开成周次逗号串，无需特判。
- **数据热更**：不重装 APK，通过更新通道下载数据包、sha256 校验后替换内置课表数据。学校换课时用。
- **`xnxq`**：学年学期参数，格式 `2026-2027-1` = 2026-2027 学年第一学期。
- **`bjid` / `encodeId`**：班级的加密 id，接口用它们而不是班级名来定位班级。
- **`jc` / `djc` / `djs`**：节次相关三兄弟——`jc` 是第几节课，`djc` 是一条课表记录的起始节，`djs` 是连堂节数。

## 登录链路

- **CAS**：Central Authentication Service，统一身份认证协议。学校的统一身份认证服务基于 CAS 实现，校验学号 + 验证码后发 ticket。
- **ticket**：CAS 认证成功后发的一次性凭证，下游系统拿它去 CAS 验证，避免重复登录。
- **aTrust**：学校部署在教务系统前的零信任网关产品（具体产品与部署细节因敏感因素暂不展开）。
- **零信任网关**：一类安全架构——不默认信任任何设备/会话，每个请求都要验证身份和设备环境后才放行。表现为「没登录时，接口请求被重定向或拦截」。
- **单会话策略**：同一账号同一时间只允许一个在线会话，在别处登录会互踢下线——这也是 App「登录成功立即缓存全量课表、刷新即重新验证码登录」的原因。

## Android 平台

- **Compose / Jetpack Compose**：Android 的声明式 UI 框架，本项目全部界面用它写。
- **RemoteViews**：桌面小组件用的受限渲染 API（不能用 Compose），所以小组件的取色要预烘焙 drawable。
- **Material You 动态取色**：Android 12+ 的特性，从系统壁纸提取配色应用到 App 和小组件。
- **BAL**：Background Activity Launch，Android 对「后台直接弹出页面」的限制。闹钟模式的直启响铃页曾被它拦过（当时改为「广播 → 全屏通知 → 尽力直启」绕行；闹钟模式已移除）。
- **Doze**：Android 深度省电模式，会推迟闹钟和网络。提醒系统为此设计了投递容差（精确 30 分钟 / 降级 60 分钟）。
- **PendingIntent**：交给系统代为执行的意图（intent），提醒排程与通知点击都用它。
- **HCT**：一种感知均匀色彩空间，materialkolor 用它从背景图提取主题种子色，取色结果更符合人眼感受。
- **sha256**：一种哈希校验。更新通道下载数据包后校验它，确认文件没被篡改或下坏。
