# 功能与实现对照

> **给谁看**：想改某个功能、却不知道它落在哪段代码的贡献者。
> **怎么用**：在「功能」列找到要改的东西 →「入口」列是用户在界面上触发它的路径 →「实现」列给出代码关键词，顺着搜就能定位文件。
> 架构背景（为什么这么设计）见 [architecture.md](../原理与接口/architecture.md)；术语含义见 [glossary.md](../glossary.md)。

## 课表

| 功能 | 入口 | 实现 |
|---|---|---|
| 班级课表 | 首次引导选班，或「更多 → 当前课表 → 换班」 | 内置数据集（228 班）打包进 APK；`Repo` + `Models.kt` 解析；无网可用 |
| 周次切换 | 课表页左右滑动翻周 | Compose Pager；`util/Weeks.kt` 周次计算 + `Merger` 连堂合并 |
| 课程详情 | 点课程块 | 详情弹层：时间/教师/教室/周次/合班；自定义颜色色板（12 色+自动） |
| 本地编辑 | 点空格加课 · 编辑卡片改节数/时间/周次 | 覆盖层架构：编辑以 `add`/`modify`/`hide` 三类记录存在本机 `user_edits.json`，学校原始数据永不改动；编辑表单在 `CourseFormSheet`，保存走 `UserEdits.saveBlock` |
| 今天跟随 | — | 课表页维护 `today` 状态 + 30 秒 ticker：跨零点、跨周自动跟进，不用手动刷新 |

## 个人课表（教务登录）

| 功能 | 入口 | 实现 |
|---|---|---|
| 短信验证码登录 | 引导页个人卡 / 更多 → 登录 | 统一身份认证 + 零信任网关全链路，纯 `HttpURLConnection`；细节因敏感因素，暂不提供相关的文档说明 |
| 专属课表 | 登录成功自动切换 | 登录后一次拉整学期 → 伪班级 `PERSONAL` 包成 `Cls`，渲染层零改动复用 |
| 刷新/退出 | 更多 → 个人课表 | 单会话策略：刷新 = 重新验证码登录；退出清 Cookie（仅内存） |
| 课表切换 | 顶栏徽标「班级课表 ⇄」或更多面板 chips | `setActiveTimetable` 统一收口；`ClassCache` 按当前模式刷写，小组件/提醒跟随 |

## 分享课表（ICS 导出）

| 功能 | 入口 | 实现 |
|---|---|---|
| 分享当前课表 | 更多 → 分享课表 → 分享当前课表 | 当前生效课表（个人含本地修改 / 班级）导出 RFC 5545 `.ics`：`data/Ics.kt` 纯函数，逐周走 `Merger` 合并（与渲染层同一套连堂语义）→ 连续周折叠成 `RRULE:FREQ=WEEKLY;COUNT=n`，Asia/Shanghai 时区；`FileProvider` + `ACTION_SEND text/calendar` 弹系统分享 |
| 帮朋友导出 | 更多 → 分享课表 → 帮朋友导出 | 临时登录对方教务账号：`PersonalRepo.fetchAll(persist=false)` 只拉不存——PersonalCache / Prefs / 内存态零写入，生成 ICS 分享后清会话；注意自己的登录会话会被让出（下次同步需重新验证码登录），登录页内有「已获对方同意」提示 |
| iPhone 导入 | 对方手机 | 把收到的 .ics 存到「文件」→ 点开 → Apple 日历「添加全部」（Google 日历等同样支持） |

> 已知限制：单周调休（如周日补上周一的课）是周循环（RRULE）表达不了的，事件落在课表标注的星期上，以学校校历为准。

## 提醒

| 功能 | 入口 | 实现 |
|---|---|---|
| 课前提醒 | 更多 → 提醒（开关 + 提前 5/10/15/20/30 分钟） | 通知链：一次排接下来至多 3 条接力闹钟 `setExactAndAllowWhileIdle`，触发→通知→重排；点行可进该通道的系统设置 |
| 下课后小结 / 早八前夜 | 更多 → 提醒（独立开关，默认关） | 与课前提醒解耦不连坐、独立通知通道（小结默认无声）；早八前夜=前一晚 21:30 且明天真有第一节 1-2 节的课才提醒 |
| 后台保障 | 更多 → 提醒 → 后台提醒保障 | 电池优化白名单 + 厂商锁定后台指引；常驻保活服务防冻结清闹钟，watchdog 断链自愈 |
| 迟到投递 | — | 投递容差：精确闹钟 30 分钟、降级闹钟 60 分钟——Doze/厂商省电推迟投递时不丢件；所有丢弃路径（缺权限/已上课）在 DebugLog 与丢弃计数留痕 |

> 闹钟模式（全屏响铃页）已在 v1.2.0-beta.6 移除：国产 ROM 对 `setAlarmClock` 的接管与冻结清理不可控，通知链成为唯一提醒路径。曾开启闹钟模式的用户自动回落为通知提醒。

| 功能 | 入口 | 实现 |
|---|---|---|
| 数据热更 | 自动/更多 → 关于 → 课表数据 · 点按检查 | 清单 `version` 对比 → 下载数据包 → sha256 校验 → 热切换，无需重装 |

| 关于页社区入口 | 更多 → 关于 → 加入社区 | QQ 群（mqqapi 直达，未装 QQ 降级复制群号）/ QQ 频道 / Star·反馈双平台选择；常量在 `ui/Links.kt`，留空自动隐藏 |
| 开发者模式 | 关于 → 连点版本号 7 次 | 时间旅行 / 测试通知·提醒链路 / 诊断报告 / `DebugLog`（logcat `kb-dev`） |

## 设计约定

- 圆角 token：28 弹层 / 22 大卡 / 18 卡片 / 16 胶囊 / 14 行卡 / 12 行内件 / 8 小件 / CircleShape 把手
- 设置行统一 `SettingRow(icon, title, subtitle, trailing)`；副标题兼作状态/错误提示并给修复动作（如「先去开通知权限」）
- 新功能文案沿用「一句人话说明 + 状态回显」文风（如「明天真有早八才提醒」）
