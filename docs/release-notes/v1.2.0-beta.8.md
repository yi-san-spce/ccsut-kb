# 长工课表通 v1.2.0-beta.8

内测版：通知体系重构——常驻保活通知彻底下线，App 关掉之后「消息提醒」通道会静默帮你盯着远程通知和课表数据更新；同时分享课表面板新增 iPhone 导入图文指南与视频教程。

## 新增

- 后台消息提醒：退出 App 后每约 45 分钟静默检查一次远程通知与课表数据更新，有新内容才发系统通知（夜间 23:00-7:00 静默不打扰）；在系统设置的「消息提醒」渠道可单独管理
- 课表数据有更新时也会在后台提醒（打开 App 后照常自动套用，无需手动刷新）
- 分享课表面板新增「iPhone 怎么导入？」图文指南：六步真机截图（微信→用其他应用打开→保存到"文件"→长按文件拖进日历→添加全部→选日历确认），内附 B 站视频教程一键打开；iOS 上 .ics 无法点开直接导入、必须拖拽，此前"点开选添加全部"的说法已修正
- 「把导入教程发给朋友」一键转发；帮朋友导出课表后，导入教程自动复制到剪贴板，粘贴发给对方即可

## 优化

- 移除「后台保活中」常驻通知：不再占用通知栏（v1.2.0-beta.6 起上课提醒本就只走通知链，无响铃闹钟，常驻保活的实际收益远小于打扰）
- 通知可靠性不降级：提醒兜底从「常驻服务每 60 秒轮询」改为「每条提醒到点 +5 分钟精确兜底闹钟」，并修复了旧轮询在提醒正常发出 5 分钟后误判断链、二次响铃的问题

## 内测须知

- 重点回归：①开启课前提醒 → 上滑划掉 App → 到点提醒照常；②发布一条新远程通知 → 不打开 App，约 45 分钟内通知栏出现；③「更多 → 后台提醒保障」的电池白名单入口照常工作；④「分享课表」面板查看导入指南、打开视频链接、帮朋友导出后确认教程已复制
- 已知边界：小米/vivo 等划卡即强停的系统上，划掉 App 且未加电池白名单时提醒可能丢（开机/重开 App 会自愈）——这正是「后台提醒保障」要解决的问题
