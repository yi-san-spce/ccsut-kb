# 长工课表通 v1.2.0-beta.4

内测版：远程公告支持一键跳转——公告的主按钮可以直接打开 App 内的功能页，不用再绕浏览器。

## 新增

- 远程公告新增 `link` 字段：点公告主按钮直接在 App 内跳转。首个支持的跳转是 `personal-login`：直达教务登录/同步页，打开时自动探测登录状态——会话仍有效就免验证码直接拉取最新个人课表，失效才需要短信验证码重新登录。选课季更新课表，收到公告点一下就到
- 旧版本完全不受影响：不认识 `link` 的版本自动回退 `url`（浏览器打开），两者都没写时按钮仅关闭弹窗

## 内测须知

- 重点回归：收到带跳转按钮的公告时，点主按钮应直接进入教务登录/同步页，而不是打开浏览器
- 跳转后：已登录用户应自动刷新个人课表并切到个人课表；未登录用户应看到登录页（手机号 + 短信验证码）
- 公告原有行为（排期窗口、版本定向、点过不再弹）不受影响
