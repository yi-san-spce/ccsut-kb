# 长工课表通 v2.9.0

课表切换一步到位 + 一轮全流程体检修复

- **课表切换一步到位**：「更多」顶部新增「当前课表」选择卡——「班级课表」「个人课表」两枚按钮，当前生效的一枚高亮，点另一枚立即切换，不用再在两个卡片之间绕路
- **课表页一键对调**：课表页顶部的「个人课表 / 班级课表」徽标现在可以直接点，在两份课表之间来回切换，小组件和课前提醒同步跟随
- **换班立即生效**：修复了在个人课表下「切换班级」选完却不生效的问题——现在选完班级直接显示新班级的课表
- **只用个人课表更顺**：引导时只登录个人课表的同学，不再每次启动都被要求选班级
- **登录更稳**：修复「获取验证码」按钮在某些失败（如账号刚在别处下线）后永久灰死、点了没反应的问题，现在会自动重试检查登录状态
- **顺手修的问题**：课表跨零点/跨周后「今天」不再停在昨天，今日高亮与今日状态自动跟进；个人课表作息数据异常时不再可能白屏，自动回退班级课表
- 已知限制不变：看课表不需要在线；「刷新」个人课表需重新验证码登录；若提示「账号已在线」请等约 3 分钟再试
