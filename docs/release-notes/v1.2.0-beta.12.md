# 长工课表通 v1.2.0-beta.12

内测版：修复 beta.11 桌面小组件无法显示的严重问题；同时增强课程药丸与玻璃字的玻璃质感。

## 修复

- **桌面小组件无法显示**：beta.11 的小组件新布局使用了桌面端不允许的 CardView 组件，导致小组件在部分桌面直接渲染失败（更新后消失/空白）。已换回框架标准容器实现，投影与圆角观感不变。**注意：升级后请长按删除旧的小组件占位，重新添加一次**

## 优化

- 小组件课程药丸玻璃感增强：药丸明显透出磨砂底（顶部 75% → 底部 40% 渐变 + 1dp 细边），替代此前接近实色的观感
- 玻璃字效果增强（App 内设置背景图 + 状态条/顶栏透明度拉满时）：新增紧贴字形暗影、柔影与描边加强、光泽面对比拉大，杂乱壁纸上轮廓清晰

## 内测须知

- 重点回归：①长按删除旧小组件占位 → 重新添加「今日课表」小组件 → 应正常显示玻璃底与投影；②拉伸 2×1 → 4×4 各档排版与议程滚动照常；③没课日空态与「下一次课」底行照常；④玻璃强度滑杆 0-100 照常（0=回实色）
- 若重新添加后仍不显示，请反馈桌面品牌与系统版本
