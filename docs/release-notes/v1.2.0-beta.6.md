# 长工课表通 v1.2.0-beta.6

内测版：移除闹钟模式、通知链大幅加固（接力提醒 + 看门狗自愈），并修复数据热更完整性等多处稳定性问题。

## 移除

- 移除闹钟模式：国产 ROM 对系统闹钟的接管双响、冻结清理等行为不可控，通知链是可维护的唯一提醒路径；已开闹钟模式的用户自动回落为通知提醒，无需任何操作

## 修复

- 修复开学前几天提醒发错周：此前开学前 1-6 天周次被截断成第 1 周，会拿第 1 周课表误发「假期提醒」
- 修复应用内自更新后提醒全灭：自更新会清掉已排提醒，现在装完即自动重排，不用等打开 App
- 修复部分 ROM 杀进程/重启后提醒断链：保活服务新增看门狗，提醒过点未消费自动补发重排
- 修复系统深浅色切换打断更新下载：下载中途切深色模式不再静默取消、弹层不再丢失
- 修复强制更新弹窗下载失败后无限重弹：失败自动收起，每轮会话最多提醒一次
- 假期/调休整周无课且作息数据异常时不再崩溃

## 加固

- 课表数据热更强制 sha256 完整性校验：清单缺校验值的数据包一律拒绝应用，防镜像投毒
- 损坏的热更数据自动隔离自愈：不再每次冷启动重复失败，可直接重新热更
- 远程数据包作息字段全部不可解析时拒绝套用，坏数据包不再影响课表页
- 个人课表缓存并发写入加锁，登录与手动同步竞态不再写坏缓存
- GitHub 官方直连通道补 APK 完整性校验（读取 Release 资产 digest）

## 内测须知

- 重点回归通知链：上课前提醒是否准时、多事件接力（一次排接下来几条）、杀进程/重启/改系统时间后提醒是否自动恢复
- 原闹钟模式用户：确认已自动回落为通知提醒，设置里不再有闹钟开关
- 更新链路：数据热更、检查更新、下载安装全流程正常
