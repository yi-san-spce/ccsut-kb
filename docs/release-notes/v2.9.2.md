# 长工课表通 v2.9.2

交互细节打磨 + 五个体检问题的修复

- **「更多」更清爽**：切到个人课表时，「当前课表」下不再显示带「换班」按钮的班级卡——换班只在班级课表模式下出现，个人课表一行搞定
- **拖拽更稳**：拖动课程时第二根手指/手掌误碰到别的课，不会再把另一门课挪错位置
- **课表不再重叠**：拖动或添加课程到已被占用的时段（周次有重叠）会明确提示并拒绝，不再出现两张卡完全叠在一起、点不开下层课的情况；周次错开的单双周同槽不受影响
- **新学期前一晚也不怕**：有新安装包待更新时，课表数据也会同步更新，不再出现「等装新版本期间课表一直是旧的」
- **个人课表自愈**：个人课表缓存意外损坏时，桌面小组件和课前提醒自动回退到班级课表，与 App 内显示保持一致
- **假期周有表态**：翻到整周没课的周次（假期/调休），网格中央会显示「本周没有课」，不再是一屏空格子
