# 长工课表通 v1.2.0-beta.14

内测版：帮朋友导出课表时可以给 TA 选课前提醒了——选项随 .ics 文件写入，导入到对方手机后每节课按所选提前量弹提醒；分享面板底部不再显示那段会话让出的长提示。

## 新增

- 帮朋友导出时可选「朋友的课前提醒」：不提醒 / 上课时 / 提前15分 / 提前30分 / 提前45分，默认提前15分；选项写入日历文件（标准 VALARM），导入到对方手机后由其日历 App 弹出（iPhone 导入日历会带上提醒；部分安卓日历可能忽略）
- 分享课表面板精简：去掉底部「帮朋友导出会用对方账号登录…」的长提示段（相关说明仍保留在登录页与导出完成后的提示里）

## 内测须知

- 重点回归：①帮朋友导出 → 登录页选「提前30分」→ 导出并用 iPhone 拖入日历 → 任一课程详情里提醒应为课前 30 分钟；②选「不提醒」导出的文件不含提醒；③分享课表面板底部不再有那段长提示
