# v2.10.4 更新说明

## 修复：v2.10.3 更新后启动闪退（重要）

- **根因**：v2.10.3 的发版构建与一次并行的代码修复**在同一分钟竞态**——安装包里裹进了那次修复**进行中的半成品代码**，而不是修复完成后的提交状态，特定数据下启动即崩。
- **修复**：从干净的已提交代码**完整重建**安装包，并经模拟器全路径验证（冷装 / 数据注入 / 2.10.2 升级路径）。
- **防再犯**：发布脚本新增硬性门禁——发版时若工作区存在未提交改动，直接拒绝发布（并行开发的半成品再也不可能混进安装包）。

## 升级说明
功能与 v2.10.3 说明一致（浅色主题显色度、课程防撞色、时间线常驻、拖拽单周化、开源双通道），本版只替换为正确构建的安装包。
