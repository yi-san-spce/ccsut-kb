# v2.12.0 · 全盘代码审查与加固

> 一次面向"成熟上架"的整体体检：12 处确认 bug 修复、隐私加固、工程化补课（测试/CI/协议）。无新功能，重点是把你已经在用的每条路径修得更稳。

## 稳定性修复（用户可见）

- **更多面板防崩溃**：远端课表数据的生成日期字段畸形时，打开「更多」不再闪退
- **脏作息不再崩溃**：教务下发的节次时间字段异常（空串/带秒）时，课表降级渲染、提醒安全跳过该节——不再崩在界面或闹钟线程
- **拖拽卡死修复**：把课块拖回原位松手后，翻页偶发被锁死 6 秒的问题修复（现在立即恢复滑动）
- **桌面小组件配色与 App 同源**：自动配色改用与主界面同一份课程稳定排序，同一门课桌面与 App 颜色口径一致，且不再出现哈希碰撞导致的撞色
- **安装更新不再"静默失败"**：未授权「安装未知应用」时，现在会引导你去系统设置授权，而不是毫无反应

## 隐私加固

- 个人课表日志与诊断报告中的学生姓名打码（诊断报告可能被整段分享）
- 教务接口逆向文档中的实测样例改用化名
- 更新下载地址强制 HTTPS：更新清单中的明文 http 下载地址将被拒绝

## 工程化（开源成熟度）

- **49 个单元测试**覆盖核心纯函数（教务响应解析、周次计算、连堂合并、本地编辑覆盖层、更新清单等）
- **GitHub Actions CI**：每次推送自动跑版本双写校验 + 测试 + 构建冒烟
- `./gradlew checkVersionSync`：build.gradle 与应用内版本号双写一致性校验（历史上失同步过一次）
- 仓库补齐 Gradle Wrapper（按 README 构建指引从零克隆现在真的能构建了）
- **开源协议由 MIT 变更为 GPL-3.0**（单一版权人变更，已装用户无感）
- 签名口令移出代码仓库（改由本机 `local.properties` 提供，不影响已装用户升级）
- 新增独立 [隐私政策](https://github.com/yi-san-spce/ccsut-kb/blob/master/PRIVACY.md) 与 [更新日志](https://github.com/yi-san-spce/ccsut-kb/blob/master/CHANGELOG.md)
