# 长工课表通 v1.2.0-beta.9

内测版：「状态条透明度」彻底重做——拉到 100% 只剩纯文字，自定义背景的头像不再被磨砂遮挡；更新与后台通知升级为横幅弹窗，到了直接弹在屏幕上方。

## 优化

- 「状态条透明度」重做：此前滑杆实际存的是"不透明度"，调到 100% 反而最不透明；现改为真透明度——0=完全不透明，100=纯文字（无底色、无磨砂模糊、无阴影），背景图上的头像原样透出；模糊程度第一次随滑杆渐变，越透明越清澈；「回到本周」药丸同步跟随；老用户的旧设置自动等价迁移，观感不变
- 更新通知与后台消息通知升级为横幅弹窗（heads-up）：新版本/新远程通知到达时直接在屏幕上方弹出，不再只躺通知栏；夜间 23:00-7:00 仍然静默不打扰
- 「iPhone 怎么导入？」六步图文指南横滑时下方内容不再上下抽动（各步文案统一单行）

## 内测须知

- 重点回归：①更多 → 自定义外观 → 状态条透明度：拉到 100% 确认背景图头像完全透出、只剩文字；调回 0% 与旧观感一致；②此前设置过旧透明度的同学确认自动迁移后外观无变化；③设置了背景图的设备，中间档位的磨砂应随滑杆变弱；④发布一条新远程通知或等新版检查横幅弹出效果（若不弹，检查系统是否关了该渠道的"横幅/悬浮通知"）
- 通知渠道升级说明：为解除老渠道"重要性不可更改"的系统限制，本次重建了通知渠道，你在系统设置里对旧渠道做过的自定义（如改过重要性）会被重置为默认
