# v2.11.3 更新说明

## 修复：重开 App 后课表类型不再"跳回班级课表"（重要）

- **现象**：选了个人课表，每次冷启动 App 却回到班级课表，得手动切回来。
- **根因**：个人课表数据的"可用性校验"在 App 首帧组合时执行一次并缓存——那时异步加载还没完成，校验结果被永久缓存为"无个人数据"，之后不再重算（除非恰逢课表数据热更），于是个人课表偏好被静默忽略。
- **修复**：把加载完成状态纳入校验的重算时机——冷启动加载完成后重新校验，上次选的课表类型原样恢复。
- 附带效果：仅用个人课表（未选班级）的用户，冷启动也不再被误引导去选班级。

## 验证
模拟器实测：个人课表 → 杀进程重开 = 个人课表；切班级 → 重开 = 班级课表，双向记忆。
