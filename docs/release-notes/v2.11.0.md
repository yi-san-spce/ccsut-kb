# v2.11.0 更新说明

## 改版：更多页成熟化

- **当前课表合并为一张卡**：课表类型切换（班级 / 个人）与当前对象信息合在一张卡里，去掉了原来与班级卡信息重复的"当前显示：…"小字；个人课表模式下同一行直接给出「同步」入口。
- **个人课表区只管账号**：未登录 = 一键登录入口；已登录 = 账号身份 + 同步 + 退出登录，职责清晰。
- **提示文案全面打磨**：统一为"信息式"表达（如"每节课开始前按时提醒"、"在课程详情里为单门课自定义颜色"），少卖萌、多说明。
- **移除「数据」区块**：手动检查更新收进「关于」页脚——点一下"课表数据 · X月X日更新 · N 个班"即检查，结果用通知条反馈；应用启动时本来就会自动检查，不再单独占一屏位置。数据热更后的"恢复内置数据"入口保留（仅发生过在线数据更新时出现）。
- 其他：退出登录图标换用系统推荐的自动镜像版本。

## 升级说明
纯界面改版，功能与设置全部无损迁移；主题风格、课程颜色、提醒设置不受影响。
