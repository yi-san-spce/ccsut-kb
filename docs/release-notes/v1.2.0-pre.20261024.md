# 长工课表通 v1.2.0-pre.20261024

抢先版：分享课表（ICS 日历导出）上线——iPhone 同学也能把课表导进 Apple 日历了；保活常驻通知改为仅后台出现，打开 App 不再被打扰。本版为强制更新。

## 新增

- 分享课表：「更多 → 分享课表 → 分享当前课表」，把正在看的课表（个人/班级，含你的本地修改）导出成 .ics 日历文件，微信/QQ 发给 iPhone 同学，对方存到「文件」后点开、Apple 日历「添加全部」即可整学期导入（Google 日历等同样支持）；单周调休暂不支持，以学校校历为准
- 帮朋友导出：「更多 → 分享课表 → 帮朋友导出」，登录对方的教务账号临时拉取 TA 的课表生成日历文件——只在内存中生成、不保存在本机、不影响你自己的课表；导出后你自己的登录会话会让出，同步自己的课表需重新验证码登录（请确保已获得对方同意）

## 修复

- 打开 App 不再被「课表提醒已就绪」常驻通知打扰：保活通知改为仅退后台后才出现，划掉后本次使用内不再恢复；提醒保活能力不受影响

## 优化

- 「更多」面板「同步」入口去重：原来个人课表在两个卡片里各有一个同步按钮，现在只保留「个人课表」账号卡里的一个

## 内测须知

- 重点回归：分享课表两个入口（自己/朋友）生成文件并能导入日历；打开/退出 App 观察常驻通知只在后台出现
- 本版为强制更新：抢先通道不可跳过
