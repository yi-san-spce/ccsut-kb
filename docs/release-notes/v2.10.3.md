# v2.10.3 更新说明

## 优化：浅色模式显色度（主题风格最后一块拼图）

浅色主题的课程块整体**加深加饱**：明度从"近白的粉彩"压到实色区间、饱和度大幅提升，主题色相真正显色——

- **卡带未来主义**：琥珀是真的琥珀黄、赤陶是赤陶，不再是奶油贴片
- **赛博朋克**：电光青/品红/荧光绿饱和度拉满，不再粉化
- **学院风**：黄铜/绯红/常春藤旧书脊色，在羊皮纸上清晰显色
- **瑞士国际主义**：灰阶压深做结构感，鲑红块更抢眼
- **极简主义**：保持克制，但墨阶与白底拉开、冷暖可辨

**课程区分再强化**：课程按排序取色板时改为**隔 3 位跨步取色**——相邻两门课的色相跳到最远（如琥珀→鼠尾草→赤陶→青），再也不会出现"前几门课全撞在同一个色系"的情况；每套色板的排列也按跨步顺序重排为冷暖/红灰交替。

深色模式配色不变（本来就 OK）。文字对比度全部复核，深色字在加饱和的浅色块上依然 6:1 以上。
