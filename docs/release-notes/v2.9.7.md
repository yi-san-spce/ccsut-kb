# v2.9.7 更新说明

## 修复

### 提醒没有弹窗/通知（重要）
- 根因：Android 13 起，`SCHEDULE_EXACT_ALARM` 权限对普通应用**默认拒绝**，提醒一直降级为非精确闹钟，在 vivo 等厂商省电策略下会被无限推迟甚至不触发——你等的那条"上课前喊你"永远不来。
- 修复：声明 `USE_EXACT_ALARM`（系统自动授予、不可撤销），课前提醒恢复**分秒不差**的精确闹钟；通知升级为高优先级 + 锁屏可见，到点直接横幅弹窗。
- 无需任何手动设置，更新后自动生效。

### 下节课倒计时小时制
- 课间倒计时超过 1 小时时不再显示"95 分钟"，改为"1 小时 35 分"；上课中的"还剩 XX"同样适用（连堂 90 分钟不再是"90 分钟"）。

## 升级建议
v2.9.6 及之前版本如果开过「贴心提醒」但从没收到过通知，更新到本版后会恢复正常。
