# 长工课表通 v2.9.3

自定义背景 · 浅色不再泛白，玻璃层次感上线

- **浅色模式不再泛白**：自定义背景上的白色蒙层在浅色模式下减到原来的一半以下（0.25 → 0.10），壁纸透出更鲜活；深色模式微降至 0.22，文字可读性不变
- **玻璃有了「厚度」**：顶栏与今日状态条的毛玻璃提亮——模糊半径 24→30dp、白色蒙版更薄（更通透），并加上液态玻璃三件套：边缘高光描边（顶部亮、底部渐隐）、顶面反光渐变、悬浮投影
- **课程块悬浮起来**：课程卡阴影加深（浅色 4dp / 深色 3dp），色块边缘加一道玻璃贴片式高光；设置了自定义背景时课程卡微微透出壁纸（97% 不透明），和背景不再是「贴纸与纸」的关系
- 深色模式同步照顾；没设背景图时观感不变（三件套只在有背景时或浅色阴影下生效）
