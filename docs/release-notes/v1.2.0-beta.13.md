# 长工课表通 v1.2.0-beta.13

内测版：桌面小组件默认尺寸调整为 4×3，并收紧纵向间距——4×3 高度下今天的课程 + 小节头可以完整露出，不再需要滑动才能看到最后一节。

## 优化

- 小组件默认尺寸改为 4×3（宽 4 格、高 3 格），重新添加小组件时按新默认摆放
- 小组件纵向间距收紧：内容区边距、议程小节头、药丸内边距、行间距整体减薄，4×3 高度下 3 节课 + 「今天 · N 节」小节头免滑动全部露出（此前最后一节被裁掉，需上滑）

## 内测须知

- 重点回归：①**删除旧小组件后重新添加** → 默认摆放应为 4×3；②当天有 3 节课时最后一节能直接看到、无需滑动；③2×2 / 2×1 等其他尺寸排版与议程滚动照常
- 已放置的小组件尺寸不会自动变化（桌面保留原摆位），需重新添加或手动拉伸到 4×3
