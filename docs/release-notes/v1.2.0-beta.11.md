# 长工课表通 v1.2.0-beta.11

内测版：桌面小组件全面改版「液态玻璃」——磨砂底直接取自桌面壁纸、卡片带真实投影悬浮、空态重设计、大尺寸可滑动看后续课程；顶栏透明度可自定义；更新弹窗滚动修复。

## 新增

- 桌面小组件「液态玻璃」改版：磨砂玻璃底直接取自你的桌面壁纸（模糊快照），卡片带真实投影悬浮在桌面上；课程药丸同步玻璃化（顶部微亮、底部微透），文字加微影保证任何强度下可读
- 小组件玻璃强度滑杆：更多 → 自定义外观 → 桌面，0=关玻璃回实色卡片，松手生效
- 小组件空态重设计：没课的日子不再是一块空板——大字居中「今天没有课」+ 底部一行「下一次 周X(M/d) HH:mm · 课程名」；明天没课会自动跨过周末/假期找到下一个有课日，期末后显示假期文案
- 小组件尺寸自适应分档：2×1 / 2×2 / 3×2 / 3×3 及以上各自最优排版，系统按实际尺寸自动切换，此前"第三节课被遮住"的问题根治
- 小组件可滚动议程（3×3 及以上）：课程区上下滑即可看今天 + 未来一周课程，按"今天 / 明天 / 周X"分组
- 顶栏透明度自定义：更多 → 自定义外观，0=毛玻璃，100=纯文字玻璃字（柔影+细描边+白色光泽三层叠字），设置背景图后生效；中间档磨砂随滑杆渐变

## 优化

- 小组件排版：标题与空态大字换重字重黑体 + 字距拉开、日期/时刻等宽数字，整体去掉全部 emoji
- App 内课程块：设置背景图后块底微透（97%→90%），高光描边升级三段式（顶亮→渐隐→底微亮），背景呼吸感更强

## 修复

- 更新弹窗「展开全部」后无法滑动查看完整更新内容（M3 弹窗 text 槽不自带滚动的遗漏）

## 内测须知

- 重点回归：①桌面小组件拉伸 2×1 → 4×4，排版应自动切换且无遮挡；②没课的日子（如周日）看新空态与「下一次课」底行；③3×3 及以上上下滑议程列表；④自定义外观 → 桌面 → 小组件玻璃强度滑杆，0 时回实色、拉满仍可读；⑤设置背景图后看 App 内课程块微透与顶栏透明度滑杆（100% 玻璃字）；⑥软件更新弹窗点「展开全部」可滑到底
- 已知边界：更换壁纸后小组件玻璃底在下次刷新时跟上（30 分钟周期 / 打开 App / 改任意设置）；议程列表为系统原生列表，个别桌面若滚动异常请反馈机型
