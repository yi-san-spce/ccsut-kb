# 长工课表通 v1.0.0

为长沙工业学院学生打造的课表查看 / 编辑 / 提醒工具：班级课表 + 个人课表 + 课前提醒 + 桌面小组件，开箱即用、离线可用，一次配置四年受用。

## 课表功能

- **班级课表**：内置全院班级课表数据集（228 个班），选班即用，无网可看；周次切换、今日状态、课程详情（时间 / 教师 / 教室 / 周次 / 合班）
- **个人课表**（可选）：学号 / 手机号 + 短信验证码登录教务系统，选课、重修课一并呈现
- **本地编辑**：点空格加课、长按拖拽换课 / 改时间、改色、隐藏、一键还原；编辑只存在本机，学校换课后自动重套

## 提醒与桌面

- **课前提醒**：每节课开始前定时通知，提前 5 / 10 / 15 / 20 / 30 分钟可选
- **闹钟模式**：采用系统闹钟语义（`setAlarmClock`），到点全屏响铃页锁屏直接弹出，不处理最多响 2 分钟自动停
- **桌面小组件**：今日课表贴在桌面，跟随当前生效课表，支持 Material You 动态取色
- **主题**：Material You 动态取色 / 液态玻璃 / 背景图取色，5 套主题风格 × 浅色与暗色

## 更新与通知

- **应用内更新**：「更新提醒」默认开启，启动与每次回到前台都会自动检查——普通更新以系统通知提醒（点按直达软件更新页，划掉通知即跳过该版本），修复类更新以强提醒弹窗展示（只有「去更新」，处理后才消失）；出现更高版本会重新提醒，设置里可随时关
- **远程通知广播**：停课调课等运营公告不经发版即可全员触达——公告推到 GitHub 仓库，所有安装包下次打开时弹窗展示，支持排期窗口、版本定向、已读去重、强提醒分级与自定义按钮文案
- **弹窗队列**：修复类更新、强提醒公告、普通公告按优先级排队，一次只弹一个，处理完自动弹下一个，已处理的本会话内不再重复
