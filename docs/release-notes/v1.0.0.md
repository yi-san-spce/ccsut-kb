# v1.0.0 · 首个公开正式版

> 长工课表通正式与大家见面。此前经过大量内部迭代与一次全盘代码审查加固（12 处稳定性修复、隐私加固、49 个单元测试、GitHub Actions CI），以此为起点对外发布 1.0。

## 功能总览（公开版全量）

- **班级课表**：内置全院班级课表数据集，选择班级即用，无网也能看；周次切换、今日状态、课程详情
- **个人课表**（可选）：学校统一身份认证手机号/学号 + 短信验证码登录教务系统，显示属于你一个人的完整课表——选课、重修课都会一并出现
- **本地编辑**：点空格加课、长按拖拽换课/改时间、改色、隐藏、一键还原；编辑只存在本机，学校换课后自动重套
- **桌面小组件**：跟随当前生效课表，Material You 动态取色
- **课前提醒**：每节课开始前定时通知，可自定义提前量
- **主题**：Material You 动态取色 / 液态玻璃 / 背景图取色 / 5 套主题风格 × 浅色与暗色
- **更新**：应用内自动检查新版本与课表数据更新（Gitee 通道），数据集可热更、无需重装

## 本版本包含的加固

### 稳定性

- 远端课表数据的生成日期字段畸形时，「更多」面板不再闪退
- 教务下发的节次时间字段异常（空串/带秒）时，课表降级渲染、提醒安全跳过该节
- 把课块拖回原位松手后，翻页偶发被锁死 6 秒的问题修复
- 桌面小组件自动配色与主界面同一份课程排序，颜色口径一致，不再撞色
- 未授权「安装未知应用」时，更新安装会引导去系统设置授权，不再静默失败

### 隐私

- 个人课表日志与诊断报告中的学生姓名打码
- 更新下载地址强制 HTTPS，明文 http 下载地址将被拒绝
- 签名口令移出代码仓库（改由本机 local.properties 提供）

### 工程化

- 49 个单元测试覆盖核心纯函数；GitHub Actions CI 自动跑版本校验 + 测试 + 构建冒烟
- `./gradlew checkVersionSync`：build.gradle 与应用内版本号双写一致性校验
- 仓库补齐 Gradle Wrapper，按 README 从零克隆即可构建
- 开源协议采用 GPL-3.0
