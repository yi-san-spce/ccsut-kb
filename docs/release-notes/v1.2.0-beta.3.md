# 长工课表通 v1.2.0-beta.3

内测版：修复闹钟双响——停止响铃后系统闹钟还在响的问题。

## 修复

- 修复闹钟双响：此前闹钟走「系统闹钟语义」注册，国产系统会把这类闹钟交给系统时钟接管自响，导致我们的响铃页和系统闹钟同时炸，停掉一个另一个还在响；现在改用精确闹钟，只响我们自己的全屏响铃页
- 修复内测清单下载地址解析：忽略条目 fileUrl 直链字段导致更新提示能弹但下载必失败（beta.2 更新弹窗正常但下载报「检查网络」的根因）

## 内测须知

- 重点回归：闹钟响铃应只有我们自己的响铃页，停止后不应再有任何铃声；若还能听到系统时钟的闹钟声，请说明设备与系统版本
- beta.2 的更新提示若因下载失败而搁置，更新到本版后链路已修复
- 常驻保活与后台响铃保障（beta.2 引入）继续生效
