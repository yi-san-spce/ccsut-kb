# 长工课表通 v2.9.5

顶栏去方框 + 开发者模式全面重构

- **顶栏不再是方框**：课表顶部的「第 N 周 · 星期」玻璃条现在底部两角收圆（贴屏幕边缘处保持贴合），消除整条方框感，与今日状态条的胶囊玻璃语言统一
- **开发者模式重构**：面板固定为八段结构——状态速览 / 时间旅行 / 即时操作 / 调试入口 / 更新通道 / 日志 / 诊断 / 危险区，信息与操作不再混排
- **长文字不再撑破卡片**：速览行的值自动折行并省略，修复「提醒」「数据」等长内容溢出方块的问题
- **新增调试入口**：对调当前课表（一键切班级/个人，验证小组件与提醒跟随）、重看引导页（回到欢迎向导第一步，设置与数据全保留）
- **速览更全**：新增课表模式、个人课表（登录人 + 缓存大小）两行状态，下次闹钟时间并入提醒行不再游离
