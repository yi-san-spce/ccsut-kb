# 长工课表通 v1.2.0-stable

正式版：内测期打磨的全部能力正式与大家见面——桌面小组件「液态玻璃」、更可靠的课前提醒、分享课表给 iPhone 同学、外观自定义全面增强。

本次为强制更新：旧版本的闹钟功能存在严重问题（误响、双响、被系统清杀不可控），已彻底移除，课前提醒统一走更可靠的课表通知链，不受影响、无需任何设置。

桌面小组件全新「液态玻璃」改版，分享课表支持 iPhone 日历导入，状态条与顶栏透明度重做——详细更新内容在「更多 → 软件更新」查看。

## 桌面小组件 · 液态玻璃

- 磨砂玻璃底直接取自你的桌面壁纸，卡片带真实投影悬浮；课程药丸玻璃化、文字加微影保证任何强度下可读；玻璃强度可在「更多 → 自定义外观 → 桌面」调节（0 = 回实色卡片）
- 尺寸自适应分档：2×1 到 4×4 各有最优排版，不再出现"第三节课被遮住"；3×3 及以上课程区可上下滑动，查看今天 + 未来一周课程
- 没课的日子显示「今天没有课」+ 下一次课的时间与名称，期末后自动切换假期文案
- 注意：升级后请长按删除旧的小组件占位，重新添加一次（新默认尺寸 4×3，最后一节课免滑动直接可见）

## 课表提醒与数据可靠性

- 移除闹钟模式：国产系统对闹钟的接管（双响、冻结、清杀）不可控，已开闹钟的用户自动回落为通知提醒，无需任何操作
- 通知提醒多级加固：多事件接力排程、看门狗自愈、杀进程/重启/自更新后自动恢复；修复开学前几天发错周、上课后补响、停了还有铃声等问题
- 常驻保活通知下线，不再占用通知栏；退出 App 后每约 45 分钟静默检查远程通知与课表数据更新（夜间 23:00-7:00 静默不打扰）
- 更新与消息通知升级为横幅弹窗，到达即见；课表数据热更强制 sha256 完整性校验、坏数据包自动隔离自愈

## 分享课表 · iPhone 也能用

- 「更多 → 分享课表」把当前课表（含你的本地修改）导出 .ics 日历文件，iPhone 同学存到「文件」→ Apple 日历「添加全部」即可整学期导入（Google 日历等同样支持），内附六步图文指南与视频教程
- 帮朋友导出：登录对方教务账号临时拉取 TA 的课表生成日历文件，只在内存生成、不落本机、不影响你的课表；可为对方选择课前提醒（不提醒 / 上课时 / 提前 15/30/45 分，默认提前 15 分）

## 外观与体验

- 状态条/顶栏透明度重做：拉到 100% 只剩纯文字，自定义背景的头像不再被磨砂遮挡；翻周、切换课表时玻璃参数串色闪变的老毛病已根治
- 时刻胶囊时间线、课程块微透与三段式高光描边、编辑误操作 8 秒内可回退、首次编辑有单步演示引导
- 修复更新弹窗「展开全部」后无法滑动查看完整内容等问题
