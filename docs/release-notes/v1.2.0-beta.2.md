# 长工课表通 v1.2.0-beta.2

内测版：新增常驻保活——上滑回桌面、锁屏熄屏后，闹钟到点照常自动全屏响铃，不再被系统冻结吞掉。

## 新功能

- 常驻保活：开启任一提醒后，通知栏出现「课表提醒已就绪」常驻通知（最低优先级，无声音），维持后台运行——退到桌面、锁屏熄屏后，到点广播准时投递，闹钟自动拉起
- 保活通知可在系统通知设置里单独关闭，不影响响铃；提醒三开关全关时保活自动退出

## 修复

- 修复退到桌面 / 锁屏后闹钟不响：进程被系统冻结导致到点广播被无限推迟，常驻保活后不再发生
- 修复内测通道收不到推送的问题（beta 条目被可见性过滤误删，v1.2.0-beta.1 已带，本版继承）

## 内测须知

- 重点测试：开闹钟模式 → 上滑回桌面，或直接锁屏熄屏 → 到点应自动全屏响铃
- 若仍不响：更多 → 提醒 → 「后台响铃保障」允许后台运行，并在最近任务里锁定本应用
- 注意：课前提醒总开关需开启，闹钟模式才生效
- 关机状态下任何应用都无法响铃（只有系统时钟的「关机闹钟」例外）
