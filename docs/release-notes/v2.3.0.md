## 长工课表通 v2.3.0（versionCode 11）

### 新增

- **背景图取色主题**：设置自定义背景图后，App 全部界面与桌面小组件自动跟随背景图配色（Material You 同款 HCT 取色算法）；删除背景图自动恢复跟随系统壁纸
- **主题配色三档切换**：外观设置新增「跟随壁纸 / 跟随背景图 / 品牌色」
- **毛玻璃质感**：设置背景图后，顶栏与今日状态条呈现实时毛玻璃效果
- **时间轴重做**：左侧时间轴改为 开始时间贴槽顶 · 节次居中 · 结束时间贴槽底
- 深色模式冷启动不再白屏闪烁；启用 Android 预测性返回手势

### 其他

- 更新通道迁移至 Gitee 发布仓（`ccsut-kb-release`），后续版本可在 App 内直接更新
