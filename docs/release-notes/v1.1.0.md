# 长工课表通 v1.1.0 · 闹钟模式 + 提醒全灭修复

> 修复「提醒全都不响」的多个根因，并上线全新的闹钟模式：到点全屏响铃，早八再也不怕睡过头。

## 新增：闹钟模式

- 「更多 → 提醒 → 闹钟模式」：开启后，课前提醒不再是普通通知，而是**全屏响铃页**——显示课程、教室、时间，点「停止响铃」结束（最长响 2 分钟自动停）
- 采用系统闹钟语义（`setAlarmClock`）：状态栏显示闹钟图标，厂商省电策略最尊重，比普通通知可靠得多
- **响铃不依赖通知权限**：即使通知权限被关，闹钟照样响
- 与课前提醒共用「提前量」档位；锁屏状态下直接点亮屏幕全屏弹出
- 开发者模式新增「10 秒测试响铃」即时验证入口

## 修复：提醒全灭（重要）

此前「课前提醒 / 下课后小结 / 早八前夜」可能全部静默不响，本版修复：

- **通知权限获取链补全**（Android 13+ 主因）：现在启动应用、完成引导、拨任一提醒开关时都会主动请求通知权限；此前只在更多面板请求一次，被拒绝后永远静默失败
- **权限被永久拒绝不再死路**：红字提示改为跳转系统应用通知设置页
- **三个开关各自独立生效**：关闭「课前提醒」不再连坐关掉「下课后小结」「早八前夜」
- **迟到不丢件**：闹钟被系统推迟（省电模式/Doze）后的投递容差从 10/35 分钟放宽到 30/60 分钟
- 补上 `VIBRATE` 权限（此前渠道开了震动但震不出来）
- 触发时缺权限不再纯静默，开发者面板可诊断

## vivo / 部分厂商手机建议

系统可能拦截后台弹通知与闹钟：请在系统设置中给「长工课表通」开启**自启动**并加入**省电白名单**（后台高耗电允许）。开不了的话，闹钟模式（系统闹钟语义）是更稳的选择。

## 升级说明

- 从 1.0.0 直接升级即可，本地数据、课表类型、登录状态全部保留
- 已装用户打开 APP 即可收到本次更新推送
