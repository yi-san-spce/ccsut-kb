# 长工课表通 v1.1.0

更新提醒全面改版：进入软件必弹更新弹窗，支持强制更新与下载进度；横竖屏切换不再丢弹窗，建议所有用户更新。

## Added / 新功能

- 更新弹窗全面改版：进入软件检查到新版本一律弹出，显示版本号与更新说明；点击「立即更新」在弹窗内走下载进度条，完成后自动拉起安装；已下载过的安装包直接变「立即安装」
- 支持强制更新：发版侧可将版本标记为强制，弹窗不可取消、不升级每次打开都会提醒（旧版本 App 自动忽略该标记，行为不受影响）
- 系统通知按版本性质区分文案：强制更新、修复更新、普通功能更新各自可辨

## Fixed / 修复

- 横竖屏切换与分屏时所有弹窗不再消失：界面改为原地重组，不再重建
- 修复更新到新版本后，旧版本安装包残留导致版本列表误显示「立即安装」的问题
- 修复关于页连点图标时步进提示要等上一条弹完才显示的问题，现在每次点击立即刷新
