# 长工课表通 v2.8.0

个人课表现已可用，强烈推荐登录体验 · 全面开源

- **推荐大家登录个人课表**：打开「更多 → 个人课表 → 登录」，用手机号/学号加短信验证码登录教务账号，选课、重修这类属于你一个人的课就会全部显示，比班级课表更完整、更准
- **安全性可靠，请放心登录**：验证码只用于登录学校教务网站，用完即弃；登录凭据只存在手机内存里，退出登录或杀掉进程即清空；不上传任何第三方服务器，不写入手机存储；课表数据只保存在你手机上
- **代码已全部开源**：整段登录与抓取代码都已公开（gitee.com/yisanspce/ccsut-kb，MIT 协议），欢迎随时审查；引导页和「关于」页都能一键跳转源码仓库
- **引导页升级**：欢迎向导里班级课表与个人课表并列选择，任选其一或都选；只用个人课表的同学不必再先选班级
- **「关于」页新增开源入口**：点击「源代码已开源 · Gitee」直达仓库
- 小提示：看课表不需要在线；「刷新」个人课表需要重新验证码登录，若提示「账号已在线」请等约 3 分钟再试
