# 长工课表通 v2.8.0

全面开源 + 引导页课表方式并列选择

- **源代码全面开源**：项目已公开在 Gitee（gitee.com/yisanspce/ccsut-kb），任何人都可以查看、审查、参与改进；引导页和「关于」页都能一键跳转到源码仓库
- **引导页课表方式并列选择**：欢迎向导精简为四屏，「认识一下」一步同时给出「班级课表」与「个人课表」两张卡片——任选其一或都选；只用个人课表的同学不必再先选一遍班级
- **个人课表实现方式透明化**：引导页直接说明个人课表是怎么来的（用你的短信验证码登录学校教务网站、只拉取你自己的课表），以及信息安全保障（验证码用完即弃、登录凭据只存本机内存、不上传任何第三方服务器、不写入手机存储），并附源码链接，欢迎随时审查
- **「关于」页开源入口**：品牌块下方新增「源代码已开源 · Gitee」，点击直达仓库
- 欢迎向导中两个课表都选时，登录成功即默认显示个人课表；之后在「更多」里随时切换
