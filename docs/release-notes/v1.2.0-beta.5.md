# 长工课表通 v1.2.0-beta.5

内测版：闹钟后台出声、上课中不再立刻响铃、保活通知可清除，并带上公告一键跳转（原定 beta.4 内容，beta.4 未发布故并入本版）。

## 新增

- 远程公告支持一键跳转：点公告主按钮直接在 App 内跳转，首个支持的是 `personal-login`——直达教务登录/同步页，会话有效就免验证码直接拉取最新个人课表；旧版本不受影响（自动回退浏览器打开）
- 选课季公告已排期上线：更新课表收到公告，点一下就到同步页

## 修复

- 修复退到桌面后闹钟「不响」：此前铃声只存在于响铃页，亮屏在后台时系统不自动拉响铃页，到点无声无息；现在亮屏在后台时由响铃通知自带闹钟铃声先出声（锁屏熄屏仍直接全屏拉响铃页）
- 修复上课中打开 APP 立刻响铃：响铃页回到前台时已过上课时刻立即静音退出；已停止的同场闹钟不再被托盘滞留通知或延迟拉起二次拉响；已过点事件的响铃通知自动清理
- 响铃最迟到上课时刻自动停止，不再越过上课时间响进课堂

## 优化

- 保活通知可清除：通知中心一键清除或左滑划掉均可，清除后不再自动恢复（直到下次进程重启），清除不影响后台保活与闹钟

## 内测须知

- 重点回归：退到桌面/锁屏后到点应有声（亮屏=通知铃声，熄屏=全屏响铃页）；点停止后不再有任何铃声；上课时刻后打开 APP 不再立刻响铃
- 公告跳转：收到带跳转按钮的公告，点主按钮应直达登录/同步页而非浏览器
- 保活通知清除后暂不找回属正常，后台保活与闹钟不受影响
