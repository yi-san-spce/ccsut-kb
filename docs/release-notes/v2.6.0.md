## 长工课表通 v2.6.0（versionCode 15）

### 新增

- **启动自动检查更新**：每次打开 APP 自动检查新版本，发现新版弹出居中更新页——新版本号、包体积、更新内容逐条展示，一键下载安装（带实时进度，失败可直接重试）；首次使用的欢迎引导页不会被打扰
- **更新内容直达**：更新弹窗的「更新内容」由发布脚本自动从版本说明生成，每次发版你都能先看到这次改了什么

### 修复

- **拖拽换课 · 松手闪烁**：拖到新位置松手后不再闪回原位置一帧再跳过去，落位动画与数据保存同帧无缝衔接
- **拖拽换课 · 跨周失焦**：拖到屏幕边缘翻周后，课程块跟着出现在新一周的页面上继续跟手拖动，不再丢失拖拽状态；松手、提交、翻页锁全部正常
- **拖拽换课 · 右缘翻周失灵**：修复从靠左的课往右拖永远触发不了「翻到下一周」的问题——现在左右两个屏幕边缘悬停半秒都能翻周，且防止落位瞬间连环翻页
- **拖拽跟手精度**：修正拖起放大后手势坐标系的偏差，课程块现在严格 1:1 跟随手指（此前有约 5% 的滞后，越往屏幕边缘越明显）
- **弹层深色模式**：课程详情/更多/添加课程弹层的文字颜色随主题自适应，深色模式下彻底解决看不清的问题
- **弹层下滑关闭**：内容滚到顶后继续下拉即可关闭，顶部把手整条可拖；自绘弹层彻底告别滚动抽搐
- 欢迎页班级选择抽屉改用同款弹层，列表滚动完全跟手
