# v2.10.0 更新说明

## 新功能：主题风格（5 套全新主题）

「更多 → 外观 → 主题风格」新增 5 套完整主题，每套自带**浅色 + 深色**双配色，与深色模式开关、课表背景图、课程块自定义颜色完全兼容：

- **卡带未来主义** — 琥珀荧光屏 + 米色面板，80 年代复古模拟电脑质感
- **极简主义** — 石墨灰阶、克制留白，纯白 / OLED 纯黑两种底
- **瑞士国际主义** — 纯黑白 + 单一瑞士红，网格与粗排版气质
- **学院风** — 羊皮纸底、黄铜与绯红，最贴大学课表的书卷气
- **赛博朋克** — 深空夜城 + 霓虹青 / 品红 / 荧光绿

### 说明
- 选中主题后，全局配色（顶栏玻璃、背景蒙层、课程块自动配色）整体由主题接管；「主题配色」（壁纸 / 背景图 / 品牌）在此时暂停生效，切回"默认"即恢复。
- 课表背景图功能不受影响：蒙层与透明度照常工作，只是蒙层颜色跟随所选主题。
- 低彩度主题（极简 / 瑞士）下课程块自动做了饱和度补偿，保证不同课程依旧一眼可辨。
- 桌面小组件暂不跟随主题风格，保持原中性配色（后续版本考虑同步）。

## 其他
- 「重置个性化设置」「完全重置」现在会一并重置主题风格。
