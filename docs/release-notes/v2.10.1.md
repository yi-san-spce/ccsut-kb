# v2.10.1 更新说明

## 优化：主题风格质感与结构（基于 v2.10.0 反馈）

### 课程块与主题同族配色
- 每套主题新增**专属课程块精选色板**（浅/暗各 8 色）：卡带=琥珀/赤陶/橄榄/雾蓝、极简=冷暖墨阶、瑞士=黑白灰+一点红、学院风=黄铜/绯红/常春藤旧书脊、赛博朋克=霓虹管青/品红/紫。
- 代替原来"全色轮散射"的自动配色，整版色调与主题气质统一，浅色下主题性格也更突出。
- **不同课程必不同色**：色板按全学期课程排序分配（不再是按课程名哈希，杜绝两门课撞色），超出色板数时同色相做明度偏移续接；桌面小组件与 APP 内同一门课永远同色。

### 主题风格归入「品牌」档，语义更清晰
- 外观区两行并一行：主题风格并入「主题配色」的**品牌**分段 [壁纸|背景图|品牌]，点"品牌"弹出选择器。
- 选择器首项为**经典品牌蓝**（原来的固定品牌色），其后是 5 套主题风格。
- 主题风格 = 固定品牌级配色，**永不随壁纸/背景图变化**；选壁纸/背景图即退出主题风格，两者不再有歧义。
- 浅色模式微调：极简主色加深近黑、瑞士描边更实、赛博朋克浅色底更冷、卡带底色更暖，浅色下主题更明显。

## 升级说明
从 v2.10.0 升级后外观设置完全兼容：已选的主题风格保持不变，入口移到了「主题配色 → 品牌」。
