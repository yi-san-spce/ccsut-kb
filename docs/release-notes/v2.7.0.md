# 长工课表通 v2.7.0

个人课表（教务登录）+ 接口技术文档

- **个人课表**：登录教务账号（统一身份认证手机号/学号 + 短信验证码）后，可查看属于你一个人的完整课表——选课、重修课都会一并显示；登录成功自动切到个人课表，随时可在「更多」里切回班级课表
- **引导页新增可选步骤**：欢迎向导里可以顺手登录，也可以点「先不登录，用班级课表」直接跳过，之后在「更多 → 个人课表」里随时登录
- **本地编辑全兼容**：个人课表和班级课表一样支持点空格加课、长按拖拽、改课/隐藏/还原与自定义颜色，且互不影响
- **小组件与课前提醒跟随当前课表**：切到个人课表后，桌面小组件和课前提醒自动改为提醒个人课表的课
- **隐私说明**：验证码只用于本次登录，账号密码不经手不存储，登录凭据只在内存里、退出或杀进程即清；课表数据只保存在你手机上
- **已知限制**：教务会话有时效——看课表不需要在线，但「刷新」个人课表需要重新验证码登录；若提示「账号已在线」，说明账号刚在别处登录或退出，等约 3 分钟再试即可
