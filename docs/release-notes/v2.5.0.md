## 长工课表通 v2.5.0（versionCode 13）

### 新增

- **本地课表编辑**：点击课表空白格子直接添加课程，默认选中你正在看的那一周，体育课等学校没提供的老师/教室信息可以自己补
- **长按拖拽换课**：长按课程块拖到其他星期/节次，逐格吸附、拖到屏幕边缘自动翻周、松手带回弹动画
- **修改标记与一键还原**：改动过的课程显示角标，详情页里有「还原」按钮；不需要的学校课程可以隐藏，不影响其他同学
- **编辑能扛住课表更新**：学校课表更新后，你的自建课程与修改会自动保留并重新吸附到新课表；确实失效的修改会明确提示，绝不破坏新课表
- **启动自动检查更新**：每次打开 APP 自动检查新版本，发现新版弹出更新页并展示更新内容，支持下载进度显示与直接安装

### 修复

- 全面重做课程详情/更多/添加课程弹层：深色模式下文字颜色随主题自适应，彻底修复看不清的问题
- 弹层支持下滑关闭：内容滚到顶后继续下拉即可关闭，顶部把手整条可拖，不再出现滚动抽搐
- 欢迎页班级选择抽屉改用同款弹层，列表滚动完全跟手
