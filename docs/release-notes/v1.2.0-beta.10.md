# 长工课表通 v1.2.0-beta.10

内测版：修复翻周/切换课表时顶栏与状态条毛玻璃"闪变"的老毛病——透明度、颜色深度不再互相串染；100% 纯文字档下顶栏也不会再突然变全透明。

## 修复

- 翻周、切换班级↔个人课表时，顶栏与「今天」状态条的毛玻璃透明度/颜色深度会随机闪变：根因是毛玻璃库 haze 1.5.x 内部的单例缺陷——两块玻璃参数不同（顶栏固定、状态条随状态换色/随透明度变模糊），滑动触发重组时会互相"借用"对方的渲染参数；已升级到 haze 1.7.3（上游重写了渲染路径）根治
- 顺带收益：新版本毛玻璃默认关闭了内部下采样，模糊画质略有提升

## 内测须知

- 重点回归：①100% 透明度下反复左右翻周，顶栏玻璃应始终保持原样（55% 底 + 固定模糊），不再闪"全透明"；②非 100% 档下翻周、切班级↔个人，两块玻璃的颜色/深度全程稳定；③滑动流畅度与上一版无肉眼差异
- 说明：翻到非本周时状态条换色（本周状态色→该周概要灰色）是既定设计，不属于本 bug
